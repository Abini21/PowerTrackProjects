# Red Black Tree
Student Name: Abini B. J  
Batch Number: 26013  
Project Title: Red Black Tree

## Description
This project implements a Red Black Tree in C, a self-balancing binary search tree that maintains balance through node colouring and tree rotations.

## Features
- Create and display the tree
- Search for a node
- Find the minimum and maximum nodes
- Delete a specified node
- Delete the minimum and maximum nodes

## Technologies Used
- C Programming
- GCC Compiler
